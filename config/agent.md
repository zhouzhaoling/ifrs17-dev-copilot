## 意图路由映射表

| 意图类别 | 触发关键词（参考） | 目标 Skill | 异常处理 |
| :--- | :--- | :--- | :--- |
| 差异排查 | 差异, 对不上, 核对, 异常, **为什么差, 比较** | `diff_analysis` | 如果查不到数据，回复“数据不存在” |
| 单点问数 | 是多少, 查一下, 口径, **查询具体数值** | `smart_query` | 如果没有口径，提示“未找到该指标定义” |
| 报告生成 | 生成报告, 导出, 写总结 | `report_gen` | 如果前置数据为空，中止生成 |

## 边界冲突仲裁规则（极重要！）
- 只要用户的问题中包含“为什么差”、“对不上”、“比对”、“排查”等意图，**必须**优先分配 `diff_analysis`。
- `smart_query` 绝对不允许用于任何涉及“比较”、“两个数据”、“新旧”的请求。
